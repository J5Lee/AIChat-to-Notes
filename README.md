# AIChat-to-Notes
A Chrome extension that sends web AI chat responses to your notes.

## What It Does

- Send responses from web AI chat services to **Obsidian** as Markdown notes.
- Add a **Send to Obsidian** button under each supported assistant response.
- Generate note titles automatically, manually, or with a **Local LLM**.

## Current Support

- Notes app: **Obsidian**
- Sites:
  - **ChatGPT**
  - **Gemini**
  - **NotebookLM**

## Planned Support

- Notes app: **Notion** (planned)
- Sites: **Claude**, **Perplexity** (planned)

## Requirements

You must install the Obsidian Community Plugin below:

- **Local REST API** (Community Plugin)

Setup in Obsidian:

1. Open `Settings -> Community plugins`.
2. Turn off Safe Mode if needed.
3. Install and enable **Local REST API**.
4. Copy the Local REST API base URL and API key from the plugin settings.

## Installation (Chrome Extension)

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this repository's `chrome-extension` folder.

## Configuration

Open the extension popup and set:

- **Obsidian Local REST API URL** (example: `http://127.0.0.1:27123`)
- **Obsidian API Key**
- **Note Title Mode**
  - `Auto`: platform + timestamp
  - `Prompt`: manual input
  - `Local LLM`: title generated by your local model (LM Studio/OpenAI-compatible endpoint)
- *(Optional for Local LLM mode)* `LLM Base URL`, `LLM Model`

## Usage

The screenshot below is from **ChatGPT** with an prompt/answer, showing the extension button under the response.

![Usage on ChatGPT](example.png)

1. Open one of the supported sites.
2. Ask your question.
3. Click **Send to Obsidian** under the assistant response.
4. Confirm or generate the note title.
5. The extension sends the Markdown note to your Obsidian vault via Local REST API.
